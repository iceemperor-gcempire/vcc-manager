# v4 업데이트 내역

## v4.0.2

### 스케치로 이미지를 만들 수 있습니다
- **Sketch to Image 작업판 3종이 추가되었습니다** (SDXL · Anima · Krea2). 스케치나 러프를 올리면 그 구도를 따라 이미지를 생성합니다. 저장소의 `workboards/` 에서 받아 등록하세요.
- **크기 걱정이 없습니다.** 올린 스케치의 비율 그대로 1M 픽셀 크기가 자동 계산됩니다 — 해상도를 고를 필요가 없습니다.
- **업스케일본이 함께 나옵니다.** 업스케일 모델(AnimeSharp 2x, Remacri 4x 등)을 골라두면 원본 크기와 업스케일본이 한 번에 저장됩니다.
- SDXL 은 컨트롤넷 6종(선화용 MangaLine 권장), Anima 는 전용 컨트롤 패치(별도 설치 필요 — 작업판 설명 참고), Krea2 는 변형 정도 슬라이더로 스케치 충실도를 조절합니다.

### 영상 참조가 더 정교해졌습니다 (MiniMax H3 R2V)
- **참조 영상의 소리를 끌 수 있습니다.** 영상마다 "소리도 참조" 스위치가 생겨, 끄면 모션·구도만 가져오고 목소리는 무시합니다.
- **소리만 참조할 수 있습니다.** 참조 오디오 칸 2개가 추가되어 영상 없이 목소리·배경음만 넣을 수 있습니다. 프롬프트에서 `<Audio 1>` 로 지칭합니다.
- 참조 영상은 앞 15초(24fps)만 사용되도록 상한이 걸렸습니다 — 긴 영상을 넣어도 안전합니다.
- R2V 작업판이 잘못된 모델을 기본값으로 갖고 있던 문제를 고쳤습니다 (#825). 참조 결과가 이상했다면 이것 때문일 수 있습니다.

### 영상 화질이 좋아졌습니다
- **기본 H.264 화질을 크게 올렸습니다** (준무손실 설정). 영상 작업판 3종 모두 적용 — 파일이 커지는 대신 압축 열화가 거의 사라집니다.
- **코덱을 고를 수 있는 (AV1) 작업판이 추가되었습니다.** 생성할 때 H.264(어디서나 재생) / VP9 / AV1(최고 효율) 을 선택합니다. ComfyUI 머신에 ffmpeg 이 필요합니다 (자세한 요구사항은 `workboards/README.md`).
- **세로 해상도가 추가되었습니다.** 영상 작업판의 해상도 목록에 각 크기의 세로판이 생겨 숏폼·모바일용 세로 영상을 바로 뽑을 수 있습니다.

### 업로드가 명확해졌습니다
- **실패하면 이유를 알려줍니다** (#842). 지원하지 않는 형식·용량 초과가 "Internal server error" 로만 뜨던 것을 고쳐, 어떤 형식이 왜 거부됐는지 팝업으로 표시합니다. 형식이 안 맞는 파일은 첨부 단계에서도 바로 안내합니다.
- **MKV 영상을 올릴 수 있습니다.** 올리면 자동으로 mp4 로 변환되어 어느 브라우저에서든 재생됩니다.

### 화면
- **작업판 카드의 제목이 한 줄을 온전히 씁니다.** 모델명이 긴 작업판 이름이 잘리던 것을 고쳤습니다.
- **갤러리 선택 창이 방금 만든 콘텐츠를 바로 보여줍니다** (#827). 생성 직후 참조로 쓰려면 새로고침해야 했던 문제를 고쳤습니다.
- 대시보드 생성 추이와 관리자 통계가 **이미지만이 아니라 영상·오디오까지** 집계합니다.

### 관리
- **계정을 삭제하면 그 사용자의 파일도 함께 지워집니다.** 이전에는 기록만 지워지고 이미지·영상·오디오 파일이 디스크에 남았습니다.
- 참조 없는 고아 파일을 찾아 정리하는 도구가 관리자 정합성 검사에 추가되었습니다.

자세한 개발 변경 목록은 GitHub issues 의 `v4.0.2` label 검색 참고.

## v4.0.1

### 작업판에 맞는 입력만 보여줍니다
- **그 작업판이 실제로 쓰지 않는 입력칸은 이제 나타나지 않습니다.** 부정 프롬프트·시드·LoRA 가 작업판과 상관없이 항상 떠 있었고, 쓰지 않는 작업판에 입력해도 아무 반영이 없었습니다. 등록된 작업판 대부분이 해당됐습니다.
- 예를 들어 MiniMax Music 3 는 부정 프롬프트를 받지 않는 모델이라 그 칸이 사라졌고, LoRA 를 쓰지 않는 작업판에서는 LoRA 영역이 보이지 않습니다.

### 생성 화면이 읽기 편해졌습니다
- **버튼이 "생성 시작" 으로 바뀌었습니다.** 음악이나 영상 작업판에서도 "이미지 생성 시작" 이라고 표시되던 것을 고쳤습니다.
- **"기본 설정 / 고급 설정" 을 "프롬프트 / 입력 항목" 으로 바꿨습니다.** 뒤쪽에는 베이스 모델처럼 반드시 채워야 하는 항목도 들어 있어 "고급" 이라는 이름이 오해를 줬습니다.
- **긴 글을 넣는 칸이 넓어졌습니다.** 가사처럼 여러 줄이 필요한 입력이 좁은 한 줄짜리로 나오던 것을 고쳐, 화면 폭을 다 쓰고 내용에 따라 늘어납니다.

### 작업 히스토리
- **오디오 작업에도 더보기 메뉴와 "계속하기 · 다른 작업" 버튼이 나옵니다.** 이미지·영상에만 있어서 오디오는 재시도나 삭제를 할 수 없었습니다.
- **오디오 필터가 추가되었습니다.** 상단 탭에서 오디오만 골라 볼 수 있습니다.

### 업로드 크기
- **파일 업로드 한도를 30MB 로 통일했습니다.** 이전에는 이미지 10MB · 동영상 100MB · 오디오 50MB 로 나뉘어 있었습니다. 이미지 10MB 는 빠듯한 반면 참조 영상은 모델 특성상 짧아 100MB 가 필요하지 않아, 하나로 합치고 중간값으로 맞췄습니다.

자세한 개발 변경 목록은 GitHub issues 의 `v4.0.1` label 검색 참고.

## v4.0.0

### 음악과 소리를 만들 수 있습니다
- **오디오 생성이 추가되었습니다.** 이미지·영상·텍스트에 이어 네 번째입니다. 작업판을 만들 때 출력 형식으로 **오디오**를 고를 수 있고, 만들어진 소리는 작업 히스토리와 내 콘텐츠에서 바로 들어볼 수 있습니다.
- **MiniMax Music 3 작업판을 바로 쓸 수 있습니다.** 분위기·장르·악기를 적으면 완성곡이 나옵니다. 가사를 넣으면 노래가, 비우면 연주곡이 됩니다. 저장소의 `workboards/` 에서 받아 가져오기로 등록하면 됩니다 (ComfyUI 서버에 모델 설치 필요).
- 만들어진 오디오는 길이·채널·샘플레이트가 자동으로 기록되고, 서버 백업에도 함께 담깁니다.

### 오디오 파일을 올릴 수 있습니다
- **내 콘텐츠에서 오디오를 직접 올릴 수 있습니다.** MP3·WAV·FLAC·OGG·M4A·AAC 를 지원하며, 올린 소리는 작업판의 오디오 입력 칸에서 참조로 쓸 수 있습니다.

### 내 콘텐츠가 정리되었습니다
- **"생성한 콘텐츠 / 업로드한 콘텐츠" 로 나뉘고, 그 아래에서 종류를 고릅니다.** 이전에는 다섯 개 탭이 생성·업로드 순서 없이 섞여 있었습니다. 이제 어디서 온 것인지 먼저 고르고 이미지·동영상·오디오·텍스트를 선택합니다.

### 작업판 화면
- 작업판 목록에서 **오디오 작업판이 음표 아이콘과 "오디오 생성" 으로 구분**됩니다. 출력 형식 필터에도 오디오가 추가되었습니다.
- 생성을 시작할 때 안내 문구가 만드는 것에 맞춰 표시됩니다 (이전에는 오디오 작업판에서도 "이미지 생성 작업이 시작되었습니다" 로 떴습니다).

### 외부 도구 연동
- **MCP 로 음악을 만들고 받아올 수 있습니다.** AI 에이전트가 작업판을 실행하고 결과 오디오를 가져가는 흐름이 이미지·영상과 동일하게 동작합니다.

### 고친 것
- **오디오 작업이 있으면 작업 히스토리 화면이 열리지 않던 문제를 고쳤습니다.** 목록 전체가 표시되지 않아 영상·이미지 기록까지 보이지 않던 현상입니다.
- **서버 백업에 오디오 파일이 빠지던 문제를 고쳤습니다.** 복원했을 때 목록에는 있는데 재생되지 않는 상황을 막습니다.
- 작업 히스토리에서 **"계속하기" 를 눌렀을 때 실제 사용했던 모델이 복원**되도록 남아 있던 경로를 정리했습니다.

자세한 개발 변경 목록은 GitHub issues 의 `v4.0.0` label 검색 참고.
