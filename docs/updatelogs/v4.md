# v4 업데이트 내역

## v4.0.0

### 음악과 소리를 만들 수 있습니다
- **오디오 생성이 추가되었습니다.** 이미지·영상·텍스트에 이어 네 번째입니다. 작업판을 만들 때 출력 형식으로 **오디오**를 고를 수 있고, 만들어진 소리는 작업 히스토리와 내 콘텐츠에서 바로 들어볼 수 있습니다.
- **MiniMax Music 3 작업판을 바로 쓸 수 있습니다.** 분위기·장르·악기를 적으면 완성곡이 나옵니다. 가사를 넣으면 노래가, 비우면 연주곡이 됩니다. 저장소의 `workboards/` 에서 받아 가져오기로 등록하면 됩니다 (ComfyUI 서버에 모델 설치 필요).
- 만들어진 오디오는 길이·채널·샘플레이트가 자동으로 기록되고, 서버 백업에도 함께 담깁니다.

### 오디오 파일을 올릴 수 있습니다
- **내 콘텐츠에서 오디오를 직접 올릴 수 있습니다.** MP3·WAV·FLAC·OGG·M4A·AAC 를 지원하며, 올린 소리는 작업판의 오디오 입력 칸에서 참조로 쓸 수 있습니다.

### 내 콘텐츠가 정리되었습니다
- **"생성한 콘텐츠 / 업로드한 콘텐츠" 로 나뉘고, 그 아래에서 종류를 고릅니다.** 이전에는 다섯 개 탭이 생성·업로드 순서 없이 섞여 있었습니다. 이제 어디서 온 것인지 먼저 고르고 이미지·동영상·오디오·텍스트를 선택합니다.

### 작업판 화면
- 작업판 목록에서 **오디오 작업판이 음표 아이콘과 "오디오 생성" 으로 구분**됩니다. 출력 형식 필터에도 오디오가 추가되었습니다.
- 생성을 시작할 때 안내 문구가 만드는 것에 맞춰 표시됩니다 (이전에는 오디오 작업판에서도 "이미지 생성 작업이 시작되었습니다" 로 떴습니다).

### 외부 도구 연동
- **MCP 로 음악을 만들고 받아올 수 있습니다.** AI 에이전트가 작업판을 실행하고 결과 오디오를 가져가는 흐름이 이미지·영상과 동일하게 동작합니다.

### 고친 것
- **오디오 작업이 있으면 작업 히스토리 화면이 열리지 않던 문제를 고쳤습니다.** 목록 전체가 표시되지 않아 영상·이미지 기록까지 보이지 않던 현상입니다.
- **서버 백업에 오디오 파일이 빠지던 문제를 고쳤습니다.** 복원했을 때 목록에는 있는데 재생되지 않는 상황을 막습니다.
- 작업 히스토리에서 **"계속하기" 를 눌렀을 때 실제 사용했던 모델이 복원**되도록 남아 있던 경로를 정리했습니다.

자세한 개발 변경 목록은 GitHub issues 의 `v4.0.0` label 검색 참고.
